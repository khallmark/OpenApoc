# Timing-source disposition ledger

This is the requirement-level provenance ledger for the render/simulation PR train. The reviewed
three-clock design is authoritative. Earlier branches, upstream PRs, issues, comments, and audit
findings are coverage and failure-case evidence; none is merge authority.

Status vocabulary: **adopt** ports a proven behavior, **replace** retains the requirement with this
plan's implementation, **lock** preserves current correct behavior, **reject** records an unsafe or
dimensionally wrong implementation, and **research** requires original-game/runtime evidence before
code. “Pending” is not an approval.

Every implementation row must eventually name a red test or immutable runtime receipt and the exact
reviewed PR head. Source links identify the upstream conversation; local commit/path anchors identify
the precise code evidence. The base for all owning PRs is reconciled head
`11ca3c08fa5bab5ac5f9871968990bd8fbe7ad00`, tree
`c6517311a9d4d16f68478ad06c982db5708f15e6`, unless a dependency is named.

## Immutable source snapshots

Requirements were re-fetched through the GitHub API on 2026-08-26. A row that names `#1166`,
`#1237`, or `#1270` means the exact code head below plus its path/symbol; conversation requirements
name immutable comment IDs separately because comments are not part of a Git head. Rows bind the
GitHub resource `updated_at` plus the complete comment-ID set observed at capture; that resource
timestamp includes comment/activity changes and is not mislabeled as a body-edit timestamp. The
capture is REST-only: it records current resource/body state and `updated_at` anchors, not GraphQL
edit history. New upstream
commits, body edits, reviews, or comments are new evidence and require a ledger delta before code.
The earlier `jq -S -c` audit digests are retained below only as
`legacy_audit_digest_unreproducible`. PR P now commits the exact allowlist, projection schema,
capture/verification implementation, and canonical source payloads. `tools/capture_timing_sources.py`
uses versioned GitHub REST, two complete corpus-wide passes A/B compared only after both complete,
complete bounded pagination, a closed
field projection, deterministic array ordering, compact UTF-8 sorted-key JSON plus one LF, and
SHA-256 over those exact bytes. It refuses repository/source/endpoint overrides, corpus drift,
missing file patches, pagination ambiguity, anchor drift, and overwrite-capable capture. The three
I1336-05 archives are downloaded only as bounded opaque temporary streams, host-allowlisted, hashed,
never extracted or committed, and deleted before success.

exact-binary receipt with pinned Data/CD/config, launch template, planned process set, realized
