## 3. Money

### 3.1 Weekly funding formula and cutoff [G1, G2, G13, G9]

**Rule.** [EXE] `FUN_000941dc` (file `0xF6880`) at the Monday-midnight rollover (first one about 5.5 days after a Tuesday-noon start), before the score rollover and before overheads:
1. Credit each org its stored income; X-COM gets the OLD income `F` (skipped if balance >= 2e9). The Government also gets 10% of the civilian wage bill plus its building net.
2. Cutoff. If latch `[0x10CA0]` is set the assessment is skipped (overheads and bankruptcy check still run). Else cut if (a) **relation leg**: signed byte `M[Government][X-COM]` < -50 (strict; -50 does not cut), or (b) **score leg**: `H` < -2400 strict, where `H` = lifetime total of all COMPLETED weeks (the eight previous-weeks words), tested alone, never `H + W`; the week being assessed never enters. A week-1 cut can only be the relation leg. Examples: -3000 then +5000 cuts at Monday 2; five weeks of -500 cut at Monday 6; +3000 then -5000 leaves `H` = -2000 at Monday 3 and no cut [G2 adjudicated].
3. On a cut: balance -= old income (undo the credit), income := 0, latch := 1 forever.
4. Else `delta` on `F` from this week's score `W` (eight categories), strict, sequential, most extreme wins: `W` > 400 +F/20, > 800 +F/16, > 1600 +F/12, > 3200 +F/8, > 6400 +F/5, > 12800 +F/4; `W` < 0 -F/15, < -400 -F/10, < -800 -F/5, < -1600 -F/4.
5. Cap: `G` = Government balance; if `G/2` <= 0 income := 0, else income := min(F + delta, trunc(G/2)); STORED as X-COM's new income (compounding); the Government is debited the NEW income.
6. Monday only: finance screen and overheads (3.2), then the bankruptcy check (3.5).

**Engine today.** [ENGINE] LIVE matches (gamestate.cpp:1765-1865; tiers data/common_patch/gamestate.xml:16-57; `previousWeeks < -2400` at :1793; 0 mismatches in 393,120 differential cases) except fidelity leftovers: the relation is a float `x < -50` (organisation.cpp:1089; G13) and the alien-dimension skip is not modelled. **HEAD diverges** (222,714 cases): D1 tests lifetime total including the current week, D2 stores income uncapped, D3 symmetric capped transfer, D4 no 2e9 guard, D5 sums 7 categories, D6 upkeep on unfinished facilities, D7 UI re-tests and resets the week (HEAD gamestate.cpp:1737-1763, weeklyfundingscreen.cpp:33-121). **Strategy consequence.** WHEN a Monday approaches THEN lifetime completed-week score must be >= -2400 and Government->X-COM >= -50 (the org screen shows "Hostile" at -50, one point before funding is cut at -51).
