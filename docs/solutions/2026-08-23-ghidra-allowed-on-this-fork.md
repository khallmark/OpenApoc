# Ghidra is allowed on this fork

This checkout is not a clean-room contribution path. Decompiler output and
`FUN_*` names are valid evidence when they carry a binary, generation
(non-4 vs `4`), and file offset.

Do not commit `depot_7661/`, original EXEs, or Ghidra `.rep` / `.gpr` databases.
Listings may live in `docs/original-game/`.

Same-session decompile plus `game/` edits is allowed. See `AGENTS.md` and
`.cursor/skills/openapoc-parity/SKILL.md`.
