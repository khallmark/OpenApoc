Verdict

OpenApoc already extracts and consumes ~30 live rule-table groups from the ISO non-4 EXEs (research, vehicles, economy, orgs, TACP equipment). The remaining original-game work is not “find more blobs.” It is logic the tables do not encode, plus a handful of hexa ranges still patched, hardcoded, or orphaned: per-mechanic 36 TPS, cover AI, manufacturing bytes, UFO growth/patterns, and hazard constants.

ISO non-4 is extractor-canonical; 4-build CRCs now slide. Depot UFO2P.EXE / TACP.EXE are the Pentium 4 builds (CRC 0xdbd3b41d / 0x3ec9c268). exe_slide.h applies +0xE00 (UFO2P, except crew_ufo_downed) and −0x2200 (TACP). Unknown CRCs log and keep slide 0.
144 TPS is intentional, not a typo. VANILLA_TICKS_PER_SECOND = 36 × TICKS_MULTIPLIER = 4. Issue 997 is a per-mechanic audit. City Speed1 now zeros city ticks on alternate frames.
32 hexa ranges have no extractor header — every range is classified. Remaining hexa-only stand-ins: senate copy. starting_available_UFOPaedia_entries / park-spawn / UFO_mission_patterns / growth / incursions / manufacturing are extracted. Do not XInclude those reference XMLs. City-side aequip/damage blobs are TACP mirrors.
Claims that did not survive the pass-3 source check. Seller credit is in (organisation.cpp:22). Manufacturing stores halt exists except Craft. Victory/defeat SMKs play. Agent unreachable fallback picks the nearest building. Panic Run can drop items. Flattened function exports stay coverage, not a named map.

  • Table offsets are bound-file offsets. Do not unbind with DOS32A.
  • Flat function export used a reconstructed LE image + BinaryLoader. Bound exports (23 Aug 2026) used LeLoader on the CRC-gated EXEs; object blocks did not apply.
