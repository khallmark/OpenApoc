Non-4 UFO2P already holds research, funding, market, and starting-relationship tables. Manufacturing is extracted from `manufacturing_data` at `0x13FD34` (names `0x1501F3`). Manufacture topic IDs keep `(` / `)` so records 38–42 (`Disruptor Armor (legs)` …) merge with patch `MANUFACTURE_DISRUPTOR_ARMOR_(LEGS)` (42 manufacturable rows; record 37 Destabiliser is 0). Case 4 is 29 rows (`XOR EBX` @ file `0x10D141`); leftover Containment `prereqTech[0]=45` is not consulted. Listing then applies record 37 All of 12..17 plus Genetic Structure, record 38 All of 8..31, and record 44 Any of 7..33. `unknown1` is the item combinator (0 All / 1 Any of three typed gates; type `0xFF` omitted). Patch `research.xml` still overlays descriptions and order. Weekly funding and most of the city economy are implemented (see alpha milestone [issue 263](https://github.com/OpenApoc/OpenApoc/issues/263)).

Aequip shop `FUN_000811fc` @ file `0xE3971` (4-build `0xE39BC`) reads only `DAT_00183b3b` — week 0 is not a hide bit. `FUN_00081774` @ file `0xE3E18` IDIVs live org `[+0xF8]` by `ammo_rounds`; the numerator is unbound (not `economy_data2`).

`Organisation::purchase` settles both sides via `settleMarketPurchase`. `Cargo::refund` credits the buyer only; the seller keeps the original `settleMarketPurchase` credit.
